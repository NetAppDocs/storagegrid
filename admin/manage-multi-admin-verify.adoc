= Manage StorageGRID multi-admin verification
:icons: font
:imagesdir: ../media/

[.lead]
Use multi-admin verification (MAV) to ensure that certain StorageGRID operations can be performed only after approvals from designated administrators. MAV prevents compromised, malicious, or inexperienced administrators from making undesirable changes or deleting data.

.Before you begin
* As a MAV requester, you have the link:../admin/admin-group-permissions.html[required access permission] for the operation you want to perform.
* As a MAV approver:
** You have the link:../admin/admin-group-permissions.html[Manage MAV requests or Root access permission].
** You're signed in to the Grid Manager from the primary Admin Node.
