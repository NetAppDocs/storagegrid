= Request approval for MAV-protected operations in StorageGRID
:icons: font
:imagesdir: ../media/

[.lead]
As a StorageGRID administrator or user, when you initiate a MAV-protected operation or command in StorageGRID, a request is generated automatically. A message appears to inform you that the operation requires approval. The operation must be approved by one or more MAV administrators.

After your request is approved, the operation or command is performed. You don't need to respond or resubmit your request after approval. If your request is rejected, the operation or command isn't performed, and you can submit a new request if needed.
