= Replace virtual primary Admin Node with SG1000/SG100 appliance
:icons: font
:imagesdir: ../media/

[.lead]
If the primary Admin Node runs as a virtual node on VMware, a non-VMware hypervisor, or a bare-metal platform, you can replace it with an SG1000 or SG100 services appliance.

CAUTION: After the replacement is complete and you have verified that the new primary Admin Node is functioning correctly, you must delete the original VM or bare-metal container. Leaving the old node running risks a major grid disruption if it inadvertently comes back online.

NOTE: Do not begin this procedure if any grid maintenance procedure is currently in progress. Wait for all maintenance to complete before replacing the primary Admin Node.
